# Tools

The scripts the checks and the maintainer use. Each runs from the repository root. `tools/check_docs.py` fails when
a file here is not listed.

| Script | What it does | Run by |
|---|---|---|
| `check.sh` | Everything CI runs, in one command, with audio cut. Exits 1 on a failure and 3 when a check could not run: the advisories check without PyPI, the workflow check without `actionlint`. | you, for CI-equivalent checks |
| `voice_loudness.py` | Measures how loud each catalogued Kokoro voice speaks before and after its gain in `src/jarvis/voices.py`, and the gain that would bring it to the median. Needs the Kokoro files; makes no sound. | you |
| `affected_tests.py` | Lists tests changed directly or selected through imports and packaged data references. Takes changed paths or `--staged`. | `hooks/`, you |
| `check_licences.py` | Every installed package's licence is compatible with GPL-3.0-or-later, and `uv.lock` resolves only from PyPI. | `check.sh`, CI |
| `check_docs.py` | Every doc is in `docs/README.md`, every ADR in `docs/adr/README.md`, every module in `docs/architecture.md`, every script here; links and backticked paths resolve; skills match their `.agents/` copy. | `check.sh`, CI |
| `get_models.py` | Downloads the wake word, VAD and Kokoro files the config uses into `data_dir` from their pinned releases over HTTPS (redirects only to GitHub's hosts), resuming a partial file, and keeps each only once its size and SHA-256 match `jarvis.models`; a file already there that differs is left alone. | `install.sh`; you, with `uv run tools/get_models.py` |
| `idle_check.py` | Reads `/proc` for a running unit or PID and fails on CPU or GPU use or memory growth while idle; where a process publishes no GPU engine time (ROCm compute), the verdict says its GPU use was not measured, and each card's whole busy share is shown beside it. Starts and stops nothing. | the maintainer, `tests/test_idle_local.py` |
| `first_audio.py` | Sends typed requests to the loaded model through the real agent and times when the first sentence reaches the speaker against when the whole reply is written (#12). Plays nothing, loads and starts nothing, and the agent has only `no_action`, so only the time saved compares with real use; refuses (exit 2) when the server is down or the model not loaded; exit 3 when a request failed. | the maintainer, `docs/playbook/README.md` |
| `get_singer.py` | Downloads SoulX-Singer's model and audio.cpp's runner from their pinned releases into `<data_dir>/sing/`, checks each file's size and sha256 before keeping it (a file already in place with the right sha256 is not fetched again, and a stopped download leaves no partial file), and takes only the runner, its libraries and licences out of the archive (about 1.3 GB). | you, once, to sing with SoulX-Singer ([models](../docs/models.md#singing)) |
| `bar_status.py` | Asks the running Jarvis for its status over the control socket and prints the line an Omarchy bar command module shows (glyph, tooltip, class), with a state for not running, a timeout, a broken connection and an unreadable answer. Standard library only, started without Python's `site` import. 0.015 s of CPU a poll. | the Omarchy bar, every 5 s, once you add it ([configuration](../docs/configuration.md#the-omarchy-bar-module-14)) |
| `router_bench.py` | Runs the same typed and spoken-style requests through Jarvis's real agent, prompt and tool schemas with `tools = "all"` and `"routed"`, for the voice and chat channels, on a model server that is already running (`--base-url`, `--key-file`). Every tool that acts is a recording stub, nothing is played, and each case runs in an empty home folder. Scores the tools and arguments of each request, counts model calls, times the first reply and the end, reads the prompt tokens the server reports, writes JSON per variant and prints the Markdown table; exit 2 when the server is not there or the model not loaded, 3 when a request failed (#56). | the maintainer, [the router benchmark](../docs/models.md#router-benchmark) |
| `router_bench_cases.json` | The requests `router_bench.py` sends, each with the calls and arguments it needs, the tools it may also call and the ones it must not. | `router_bench.py` |
| `wake_train.sh` | Trains and scores one LiveKit wake phrase on the training machine with a chosen LiveKit project's key file (mode 0600, read as data); stops before training, exit 3, when that project's speech credit ran out, so a rerun with another key picks up from the cache. | the maintainer, [wake training](../docs/playbook/wake-training.md) |
| `wake_ungated.py` | Runs the wake word trainer without its two gated test sets (ESC-50, GTZAN) until access is granted (#37); stops if the trainer is not the version it was checked against. | `wake_train.sh --ungated` |
| `wake_bench.py` | Benchmarks wake word models on local voices they never heard (clean, quiet, with TV and music at 10 to 0 dB, with echo, far away), on Jarvis's own replies and on about 24 h of real media, and replays the media through the models together as Jarvis listens. Prints counts with 95 % intervals: false wakes an hour on media the threshold was not picked on, recall per condition, voice group and text, and paired differences between models. | the maintainer, [wake training](../docs/playbook/wake-training.md) |
| `install-hooks.sh` | Copies the hooks in `tools/hooks/` into this clone's own hooks folder, shared by its worktrees (`--uninstall` removes the copies). Run it again after a hook changes: a copy does not follow the branch. | you, once, if you want the hooks, and after a hook changes |
| `hooks/` | `pre-commit` runs lint and affected non-local tests. `commit-msg` checks the Conventional Commits subject and warns on a missing sign-off. All three hooks, including `pre-push`, refuse private details. | git, after `install-hooks.sh` |
| `check_private.py` | Nothing about one person or machine: real e-mail addresses and home folders, this PC's host name and home, the global git identity, and the terms in the maintainer's private list (`.git/info/private-terms`, never committed). `--staged`, `--message` and `--push` check a commit or a push. | `check.sh`, CI, the hooks |
| `check_pr_commits.py` | Every non-merge commit in a range has a Conventional Commits subject with a listed type, and, with `--signoff required`, a sign-off naming its author. | CI (`pull-request-commits.yml`), you |
| `ci-tool-install.sh` | Pinned downloads of uv, the shell checkers and actionlint, verified by sha256. | CI |

# Looking things up about a game

1. Name the game and the exact thing in the search: "elden ring moonveil katana", "wow
   thunderfury blessed blade". Add the game version or expansion when the owner named one, since
   items and builds change between patches.
2. The best sources are the game's main wiki and database sites (for example Wowhead for World
   of Warcraft, Fextralife or Fandom wikis, the official site or patch notes). Search with the
   site's name to reach them ("wowhead thunderfury").
3. web_read the item's or quest's own page, not a list or a forum thread, when the snippet doesn't
   give the details asked for.
4. Answer with what the owner asked for: where to get it, its stats, requirements, the steps of a
   quest. Use a short list or a table for stats. Name the source and the patch the page is for.
5. When pages disagree, trust the most recent page for the current version and say they differ.

# Questions about the PC

1. Call pc_stats for anything about the CPU, the graphics card, VRAM, memory, temperatures,
   disks or uptime: the numbers change by the second, so never answer them from memory.
2. Answer the question asked, not the whole report: "how hot is the GPU" gets the graphics
   card's temperature, maybe its load.
3. Help read the numbers: under about 80 °C is normal for a CPU or graphics card under load,
   above 90 °C is hot. Memory or VRAM above 90% used is nearly full. A load average above the
   thread count means the CPU has more work than it can run at once.
4. The local model that runs you lives in the graphics card's memory, so VRAM is never near
   empty; say so when the owner asks why it is high.
